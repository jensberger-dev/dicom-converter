Privacy policy

1. Controller

The controller responsible for data processing on this website is Dr. Jens Berger (contact details see legal notice).

2. The essentials in brief

  • This website sets no cookies and does not load fonts, maps or videos from third-party servers.
  • Visits are counted anonymously (see section 4). Your IP address is not stored for this.
  • The DICOM-Converter itself works exclusively on your computer. Patient data are transmitted neither to this website nor to the publisher. Only to find new versions does the program query this website at startup (see section 3; can be switched off).

3. Hosting and downloads (GitHub)

This website and the installers are provided via GitHub Pages and GitHub Releases. The provider is GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. When you visit the page and download a file, GitHub processes technically necessary data, in particular your IP address, date and time of access and information about browser and operating system, in order to deliver the content and ensure the security of the service. Data may be transferred to the USA in the process; GitHub is certified under the EU-US Data Privacy Framework. The legal basis is Art. 6(1)(f) GDPR (legitimate interest in reliable and secure provision of the page and the programs). GitHub also counts how often each file has been downloaded; this number contains no personal data.

Checking for new versions in the program: when the program window starts, the DICOM-Converter retrieves the file aktuell.json (version number and changes) from this website and, if you wish, downloads the new installer from GitHub Releases. GitHub processes the same technically necessary data as when the page is visited (IP address, time) as well as the program’s version number. No other information, patient data or files are transmitted, and the own counting service (section 4) is not used for this. The check can be switched off in the program under Hilfe → Beim Start nach neuen Versionen suchen (Help → check for new versions at startup). The legal basis is Art. 6(1)(f) GDPR (legitimate interest in informing users about new and improved versions). Further information: GitHub’s privacy statement.

4. Anonymous visitor counting with the origin of the institution (Cloudflare)

To find out how often the page is visited and which installers are clicked, the page reports visits and clicks on the download buttons and the donation link to an own counting service operated at Cloudflare (Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA; certified under the EU-US Data Privacy Framework). Your IP address is only used briefly to derive the country, region and – where recognizable – the name of the network the access comes from (e.g. a university or hospital); access via internet providers for private customers is only counted as “private/provider”. For each event, only the day, type of access, country, region, browser, operating system, the referring page and, where applicable, the name of the institution are stored – not the IP address, no time of day and no cookies. It is not possible to link this to individual persons. The legal basis is Art. 6(1)(f) GDPR (legitimate interest in data-minimizing audience measurement, also to find out in which institutions the program is used). Further information: Cloudflare’s privacy policy.
